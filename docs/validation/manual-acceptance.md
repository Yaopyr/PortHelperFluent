# 人工验收清单

以下项目依赖真实硬件、外部软件或真实系统副作用，源码级模拟无法完整替代。逐项勾选后再把结果补进对应版本的验证报告；未执行的项目保持 `MANUAL（待执行）`，不得计为 PASS。

| ID | 项目 | 操作步骤 | 通过标准 |
|---|---|---|---|
| MAN-01 | 真实串口 | USB 串口或回环线：枚举、打开、改波特率/数据位/停止位/校验/流控、文本/HEX 收发、DTR/RTS/BREAK、连续发送、文件发送、会话导出 | 收发字节一致；线路状态灯随设备变化；无丢包/卡死；导出可打开 |
| MAN-02 | 真实 HID | 标准 HID 设备：枚举、搜索、打开、报告 ID/长度、读写、连续/文件发送、拔出 | VID/PID/Usage 正确；报告长度符合设备；拔出后自动复位且不崩溃 |
| MAN-03 | 真实 BLE | 手机 BLE 工具或透传模块：扫描、连接、服务树、读/写、通知订阅、MTU/RSSI | 服务/特征值正确；读写与通知内容一致；MTU 显示系统值；断开可恢复 |
| MAN-04 | 真实 SPP | HC-05/JDY-31 等：未配对设备一键连接（PIN 1234）、已配对 RFCOMM 收发、系统蓝牙 COM 口回退 | 配对码弹窗正确；RFCOMM 与 COM 通道均可收发；模式切换自动断开 |
| MAN-05 | 真实网络 | 外部主机/手机：TCP/UDP、域名、Ping、网卡信息、多客户端与广播、防火墙 | 连接/收发/广播正确；错误提示可读；默认网关显示正确 |
| MAN-06 | 校验对比 | 用独立 CRC/Intel HEX/TCP-IP 工具计算 `123456789` 与随机文件 | CRC-32=CBF43926、MODBUS=4B37、CCITT-FALSE=29B1、MAXIM=A1；文件结果一致 |
| MAN-07 | 图片输出 | 将 C/BIN/LVGL8/LVGL9 输出到目标屏或查看器 | 像素、尺寸、扫描方向、字节序与颜色正确 |
| MAN-08 | 点阵输出 | 将点阵 C/BIN 输出到真实 LED/OLED 面板 | 字体、分页、点阵方向、位序、单元格编辑结果正确 |
| MAN-09 | Keil 工程 | 用 Keil uVision 打开 `M51Project.Uv2` 并编译 | 工程可打开、`Main.c`/`STARTUP.A51` 可编译；定时/波特率与向导一致 |
| MAN-10 | 真实更新 | 发布正式 Release：检查更新、下载、SHA-256、确认安装、重启；再测试回滚 | exe 被替换且版本更新；校验失败不安装；失败可回滚 |
| MAN-11 | 无 Python 环境 exe | 在干净 Windows 目录（无 Python）运行 `PortHelperFluent.exe --selftest` 与 `--smoke-test` | 退出码 0；图标/资源/数据目录正常；无缺 DLL |
| MAN-12 | 音频播放 | WAV/MP3 载入、播放、停止、导出 C/H | 声音正常；停止生效；导出数组长度与采样率正确 |
| MAN-13 | 视觉/系统 | 浅色/深色、强调色、Mica、DPI 缩放、长文本/最小窗口 | 无裁切/重叠/白屏；文字可读；页面切换流畅 |
| MAN-14 | 便携/只读 | `portable.flag` 便携模式；程序目录只读 | 便携数据写入 `data\`；只读时回退 AppData 并给出提示 |
