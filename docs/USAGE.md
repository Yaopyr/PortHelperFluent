# 使用指南

本文按页面说明常用操作与注意事项。主窗口左侧导航分为「通信 / 工具 / 其他」三组。

## 通用

- 主题、强调色、退出确认在「设置与关于」中即时生效；显示行数、日志字号等显示设置在下次启动应用时生效。
- 所有收发区支持 HEX/文本、时间戳、暂停、自动滚动、清空、复制当前显示、保存 TXT/CSV；暂停只停刷新，不停记录与计数。
- 日志上限默认 8 MB；达到上限会丢弃最早记录，界面显示「会话记录已截断」，TXT 导出带说明。
- 配置默认在 `%APPDATA%\PortHelperFluent\config.json`；日志在 `logs\app.log`。
- 便携模式：exe 同目录放 `portable.flag`，配置/日志写入 `data\`。

## 快捷键

| 快捷键 | 作用 |
| --- | --- |
| `Ctrl+Enter` / `Ctrl+Return` | 在当前发送框发送（串口、网络页面） |
| `Ctrl+K` | 清空当前日志面板 |
| `Ctrl+S` | 保存当前日志/导出当前结果（页面相关） |
| `F5` | 刷新串口、HID 或网卡/适配器列表 |

## 串口调试

1. 点击「刷新」枚举串口；端口下拉可直接输入手动端口（如 `COM7`）。
2. 设置波特率、数据位、停止位、校验、流控、字符编码；点击「打开串口」。
3. 打开后可切换 DTR/RTS、发送 BREAK；CTS/DSR/RING/RLSD 为只读状态。
4. 接收区/发送记录在 Tab 中查看；HEX、时间戳、暂停、自动滚动按需切换。
5. 发送区支持文本/HEX、末尾 CR/LF/CRLF、连续发送间隔、发送文件、多项发送。
6. 「会话记录」查看完整收发记录并导出 TXT/CSV；「重新计数」只清零接收/发送字节计数。

提示：

- HEX 输入支持空格、逗号、换行、`0x`/`\x` 前缀；奇数长度或非法字符会就地报错，不会发送半截数据。
- 文件发送按真实写入确认逐块推进；发送过程中发送按钮会禁用，避免与普通数据交错。
- 本页是「本程序自己的收发记录」，不是系统级串口监视。

## 蓝牙调试

页面顶部的分段控件切换 **低功耗蓝牙（BLE）** 与 **经典蓝牙（SPP）**。右列日志与发送区两种模式共用，切换模式保留日志并插入一条系统分隔线；打开页面**不会**自动扫描或自动连接。同一时刻只保留一条活动连接。

### 低功耗蓝牙（BLE）

1. 选择扫描时长（5/10/20 秒，默认 10 秒），点击「开始扫描」；扫描期间显示剩余秒数，可随时停止。
2. 用过滤框按名称或地址筛选，排序可选「信号强度 / 名称 / 最近发现」；「仅显示有名称」可隐藏无名设备。
3. 选中设备后点「连接」。连接成功后设备信息卡显示名称、地址、服务数、当前 MTU 与最后一次广播的信号强度。
4. 「服务与特征值」树显示服务 UUID 与已知名称（如 `FFE0（自定义）`）、特征值属性徽章（Read/Write/WriteNoRsp/Notify/Indicate）与订阅状态；可展开全部、折叠全部、按 UUID 过滤。
5. 选中特征值后可「读取」「订阅/取消订阅」「写入」「复制 UUID」。写入只是把焦点移到右列发送区；订阅后收到的通知按特征值 UUID 前缀写进日志。
6. 右列发送区顶部显示「写入目标：<特征值>」，未连接或没选中可写特征值时发送按钮禁用。默认「写入需应答」与「按 MTU 分片」（按 MTU-3 分片）。
7. 「忽略空通知」默认开启：设备周期性空包只计入计数（计数行显示「忽略空通知 N 包」），不写日志，避免刷屏。

### 经典蓝牙（SPP）

1. 点击「开始扫描」（一次探寻约 12 秒，可随时停止）；过滤框按名称/地址筛选，「只看已配对设备」只显示系统已配对的设备。
2. 选中设备后点「一键连接」：已配对设备直接建立 RFCOMM 通道；未配对设备先自动配对。
3. 配对时按系统要求弹窗：
   - 需要 PIN 时弹出「输入配对码」，预填 `1234`（HC-05/JDY-31 一类模块的常见默认值），可改成模块实际 PIN；1–16 位数字，非法值会就地报错。
   - 只要求确认时弹出应用内确认框，显示系统给出的配对码，需在两台设备上核对一致后点「是」。
4. 配对成功后自动接着连 RFCOMM；按钮下方按阶段显示「配对中…」→「连接中…」→「已连接」。
5. 「通道信息」显示设备名、地址、通道（RFCOMM 或 COMx），COM 通道还显示当前波特率。
6. 数据收发、HEX、行尾、连续发送、文件发送（4 KiB 分块）、多项发送与会话导出都在右列，与串口页一致。

### 备用通道：系统蓝牙 COM 口

RFCOMM 直连失败、或蓝牙驱动没有为设备创建虚拟串口时使用「备用通道（系统蓝牙 COM 口）」：

1. COM 口下拉自动列出描述或硬件 ID 含「蓝牙/Bluetooth/BTHENUM/BTHMODEM/RFCOMM」的端口，也可直接输入（如 `COM5`）。
2. 设置波特率（默认 115200；老模块常用 9600、19200、38400、57600、230400）。
3. 点「打开 COM 口」开始收发；再点一次即断开。

RFCOMM 与 COM 通道不能同时存在：切到 COM 通道会先断开 RFCOMM，反之亦然。

### 收藏、别名与上次设备

- 设备表右键菜单：连接、收藏/取消收藏、重命名（别名）、复制地址。收藏的设备置顶并带星标，别名优先于广播名称显示。
- 页面记住上次连接的设备（地址与名称），下次打开自动选中但**不自动连接**；需要自动连接时显式打开「打开页面自动连接上次设备」开关（默认关闭）。
- 收藏列表、别名、上次设备、模式、HEX 选项、波特率等保存在配置文件的 `bluetooth.*` 键。

### 蓝牙不可用时的排查

- 扫描/连接/配对失败时，状态条与日志给出中文原因与下一步建议，并弹出错误提示；失败后面板右上会出现「打开蓝牙设置」按钮，可直接打开 Windows 蓝牙设置（等同于 `ms-settings:bluetooth`）。
- 没有蓝牙适配器、系统蓝牙被关闭或被设备管理器禁用时，先打开系统蓝牙确认适配器可用，再重新扫描。
- 常见提示：「确认设备在广播范围内，且系统蓝牙已打开」（扫描失败）、「确认设备未被其他程序占用，且已开机」（连接失败）、「先让设备进入配对模式（指示灯快闪）」（配对失败）。
- 配对失败会区分 PIN/配对码错误、认证超时、设备拒绝。反复失败时先在 Windows 设置里手动配对，再用「一键连接」或 COM 备用通道。
- MTU 与连接后的信号强度都是只读的：Windows 由系统协商 MTU（可用刷新按钮重读），BLE 设备连接后一般停止广播，所以信号强度只显示最后一次广播的值并标注停更。

## 网络调试（TCP/UDP 客户端）

1. 选择 TCP 或 UDP。
2. 输入目标 IP 或域名；可先点「域名转 IP」查看解析结果。
3. TCP：填写源/目的端口，点击「连接」；UDP：填写本地绑定端口和目标端口，点击「绑定」。
4. 使用 TCP/UDP 发送按钮分别发送；接收区按协议分 Tab。
5. Ping、域名转 IP、网卡信息、会话记录在辅助区。Ping 调用系统 `ping.exe`，不做原始套接字 ICMP。
6. 连续发送/文件发送与串口页一致；UDP 域名发送会异步解析，解析失败不会产生假的 TX 记录。

提示：

- 域名/IP 解析和网卡读取在后台线程执行，不阻塞界面。
- 目标端口不可达、被防火墙拒绝、DNS 失败等会显示中文原因。
- 网卡信息中的网关来自系统默认路由 `route print -4`。

## 网络服务器

1. 选择监听地址（`0.0.0.0` 表示全部网卡）和端口；端口 0 表示系统自动分配。
2. 设置最大客户端数（1–64），点击「启动」。
3. 客户端列表显示 IP:端口、连接时间、RX/TX 字节；选中客户端后可单独发送。
4. 勾选「广播」向所有客户端发送；接收区带来源 `IP:端口` 前缀。
5. 支持断开选中客户端、连续/文件发送、会话导出。
6. 关闭页面或退出应用会停止监听并断开全部客户端。

## USB HID

1. 点击「刷新」枚举标准 HID 设备；可用搜索框按 VID/PID/产品名过滤。
2. 选中设备，设置报告 ID（0 表示无编号报告）与报告长度（默认 64 字节），点击「打开」。
3. 接收区显示 Input Report；发送区发送 Output Report。带编号报告时首字节为报告 ID。
4. 设备拔出或读写失败会自动关闭并提示。
5. 本页只支持标准 HID；CH372/CH375 需要厂商 DLL，不在支持范围。

## 校验计算

1. 选择输入模式：文本、HEX 或文件。
2. 选择编码（ANSI/GBK/UTF-8）；文件模式显示进度并可取消。
3. 结果表包含 Sum-8/16/32、XOR/BCC、奇偶校验、Intel HEX、TCP/IP、CRC-8/16/32 预设；可勾选「计算后取反」，切换 16/32 位字节序。
4. 「自定义 CRC…」可输入宽度 8/16/32、poly、init、xorout、refin/refout，适合非标准变体。
5. 下方源码预览展示本程序对应算法的 Python 实现，便于移植；它不是原程序的源码。

已知向量可自行核对：CRC-32/ISO-HDLC("123456789") = `CBF43926`，CRC-16/MODBUS = `4B37`，CRC-16/CCITT-FALSE = `29B1`，CRC-8/MAXIM = `A1`。

## 编码转换

页面用分段控件切换 7 个工具：

1. **进制转换**：输入 2–36 进制，输出二进制/八进制/十进制/十六进制；支持 32/64 位与有符号补码视图。
2. **Bin/Hex/Text**：Bin→Text（字节转大写十六进制文本）、Hex→Text（十六进制文本按编码解码）、Hex→Bin（十六进制文本转原始字节）。
3. **数码管**：输入 0–9/A–F，或点击 a–g/dp 段；输出共阴/共阳 HEX 与 BIN。
4. **调色板**：颜色选择器 + RGB/HEX，输出 RGB888/RGB565/RGB332；用于彩屏与二维码位图调色。
5. **GIF→BMP**：载入 GIF，逐帧预览/调速，设置宽高，批量导出 `名称_0001.bmp`。
6. **音频→C**：载入 WAV/MP3，显示格式/采样率/声道/时长，播放/停止，导出 `.c/.h`。MP3 需要 ffmpeg。
7. **二维码**：输入文本，选择纠错等级 L/M/Q/H、尺寸、边框、前景/背景色，保存 PNG/BMP。

## 图片取模

1. 选择单张图片或文件夹；支持拖放。
2. 设置输出类型（C/BIN/LVGL8/LVGL9）、扫描方式（水平/垂直）、方向（四向）、位深（1/8/16/24/32）、字节序（仅 16 位）、输出宽高、背景色、1 位阈值、反色。
3. 左侧原图与右侧输出预览；参数变化实时刷新。
4. 「转换/保存」导出单个文件；「批量转换」处理文件夹，显示进度/失败列表；同名文件自动加序号。
5. C 文件包含尺寸、格式、扫描方式注释；BIN 为原始数据；LVGL 输出为描述符文本。
6. 输出像素上限 1600 万，超过会提示减小尺寸。

## 点阵生成

1. 选择「文字」或「BMP」输入。文字使用系统字体，可设字号 8–64、粗体/斜体；BMP 可设阈值/反色。
2. 设置扫描方式、取模走向、位序（MSB/LSB）、每页字符数、点/背景色、网格与缩放。
3. 预览区按页显示；单击单元格可切换黑白，编辑结果参与导出；「恢复文字」可重新渲染。
4. 导出 C 数组、BIN；BMP 文件夹可批量生成独立 C 文件。
5. 长文本自动分页；C 输出包含宽高、扫描方式、位序、页数注释。

## C51 向导

1. 设置晶振频率（0.1–100 MHz）、6T/12T；选择端口 P0–P3 引脚。
2. 配置中断（EA/EX0/ET0/EX1/ET1/ES/ET2、优先级、外部中断触发方式）。
3. 配置定时器 0–2（模式、门控、运行、定时时间/重载）；串口方式、波特率、REN/SM2/TB8/RB8/SMOD/发生器。
4. 设置功耗模式与软件延时；警告面板汇总冲突/溢出/建议。
5. 「生成」刷新 C 代码预览；「导出 C」保存 `Main.c`；「导出 Keil 工程」保存 `Main.c`、`M51Project.Uv2`、`M51Project.Opt`、自写 `STARTUP.A51`。
6. Keil 工程需要在真实 Keil 中打开验证；生成的 `STARTUP.A51` 是本项目自写的最小启动文件，不复制 Keil 原文件。

## 设置与关于

- 主题：跟随系统/浅色/深色，强调色可选；立即生效。
- 默认编码：页面没有自己的编码设置时使用；下次启动生效。
- 最大显示行数、自动滚动、退出确认、日志字号：显示类设置在下次启动生效，退出确认立即生效。
- 路径：打开配置/日志目录，导出配置，重置配置。
- 关于：版本、独立复刻声明、原程序参考、明确不支持项、依赖许可、REA 证据说明。
- 更新：卡片显示当前版本；「检查更新」手动查询 GitHub Releases 最新正式版，「启动时检查」开关可关闭启动时的静默检查（默认开启）。
- 发现新版本时显示更新说明；点「下载并安装」后台下载并校验 SHA-256，确认后程序关闭、替换 exe 并自动重启（会先断开串口/网络/HID 连接）。
- 下载包、备份、安装脚本与 `update.log` 都在 `%APPDATA%\PortHelperFluent\updates`，不会在 exe 所在目录（如桌面）留下文件（写权限探针创建后立即删除）；便携模式落在 `data\updates`。
- 源码运行（`python main.py`）只下载不替换，按提示手动替换打包后的 exe。

## 故障排查

| 现象 | 处理 |
| --- | --- |
| 串口打开失败 | 检查端口占用、设备连接、权限；看日志中的具体错误 |
| HID 列表为空 | 确认是标准 HID；点击刷新；检查设备驱动 |
| TCP 连接被拒绝 | 确认对端已监听、端口正确、防火墙放行 |
| UDP 无接收 | 确认本地绑定端口、目标端口、目标地址；检查防火墙 |
| MP3 转换失败 | 安装 ffmpeg 并加入 PATH，或改用 WAV |
| 打包后启动白屏/报 qfluentwidgets 版本 | 见 [构建指南](BUILDING.md#启动时报-qfluentwidgets-不是-pyqt6-版本) |
| 配置损坏 | 程序会备份为 `config.bad-*.json` 并恢复默认；也可在设置页重置 |
