# AI Agent CLI 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 让同一个 `PortHelperFluent.exe` 同时承担 GUI 与面向 AI Agent 的无头 CLI，覆盖现有全部功能。

**Architecture:** 新建 Qt 无关的 `app/cli/` 分层；离线命令直接调用 `app/core`、`app/services`，硬件命令复用现有 Qt-free 后端类，网络用标准库 socket。`main.py` 先判断子命令并分流；PyInstaller 改为控制台子系统并用 `hide_console="hide-early"` 只在程序自己拥有控制台时隐藏窗口。

**Tech Stack:** Python 3.13、argparse、PyInstaller 6.19、pytest、现有 PyQt6/pyserial/hidapi/bleak/WinRT 依赖。

**Spec:** `docs/superpowers/specs/2026-11-01-cli-design.md`

## Global Constraints

- 只分发一个 `dist\PortHelperFluent.exe`；不得新增第二个 exe、批处理或 PowerShell 包装脚本。
- 不新增运行时依赖；只使用标准库与 `requirements.txt` 已有包。
- 仅支持 Windows；源码运行入口为 `python main.py <args>`。
- `APP_VERSION` 与 `build/version_info.txt` 统一升到 `1.2.0`。
- CLI 默认 JSON；信封固定 `ok/command/version/elapsed_ms/data` 或 `ok/command/version/elapsed_ms/error{code,message,details?}`。
- 退出码：0 成功、1 未预期异常、2 用法、3 操作失败、4 期望未命中/超时、130 中断。
- 所有 CLI 输出 UTF-8；`--format text` 仅用于人工查看，流式命令不接受 text。
- CLI 不创建 `QApplication`、不弹模态框；离线命令路径不得导入 PyQt6。
- 流式命令必须给 `--duration`（1–3600 秒），并提供 `--max-bytes` / `--max-events` 上界。
- 除 `config set/reset`、`update install`、`selftest` 外，CLI 不修改用户状态；`config reset`、`update install` 必须 `--yes`。
- 现有 755 项测试必须继续通过；新增测试计入基线并同步文档计数。
- 工作区已有与本次无关的未提交改动（`.gitignore`、`README.md` 的模拟验证段落、`pytest.ini`、`tests/simulation/`、`tools/`、`docs/validation/`、`pytest-sim.ini`）。不要修改或提交它们；每个 commit 只 `git add` 本任务列出的路径。

## Review Focus

1. **双击 GUI 出现控制台窗口 / 从 shell 调用 CLI 不等待**：Task 18 用 spec 文本断言和 Task 20 的 build + 手工验收覆盖；双击必须只见 GUI，PowerShell 调用必须返回 JSON 与退出码。
2. **`--expect` 的回包被拆成多次读取**：Task 1 的 `read_until` 测试必须覆盖 `[b"O", b"K"]` 跨块匹配。
3. **流式命令无数据时永久挂起**：Task 12、14、16 必须用假后端/假时钟验证到 `--duration` 自行结束。
4. **离线 CLI 间接导入 PyQt6**：Task 2 用子进程断言 `import app.cli.main` 后 `PyQt6` 不在 `sys.modules`；后续任务不得破坏。
5. **HID 设备 path 是任意字节，不能当 UTF-8 文本**：Task 15 用 `b"\xff\x00"` 验证 `--path-b64` 往返。

```python
def collect_selftest_report() -> dict[str, Any]:
    # 复制 run_selftest 的报告构造逻辑，不写文件
def run_selftest(report_path=None) -> int:
    report = collect_selftest_report()
    exit_code = 0 if report["ok"] else 1
    # 原有的 write_text_atomic 与写失败处理保持不变
def main(argv=None) -> int:
    argv = list(sys.argv[1:] if argv is None else argv)
    from app.cli import is_cli_invocation
    if is_cli_invocation(argv):
        from app.cli.main import run
        return run(argv)
    # 以下保持现有 argparse 与 GUI 启动
```

`app/cli/__init__.py` 只定义 `CLI_GROUPS` 与 `is_cli_invocation`，不导入 Qt 或命令模块。

`app/cli/main.py`：
