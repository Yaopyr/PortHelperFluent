# PortHelper Fluent 设计规格

- 日期：2026-10-26
- 状态：已获方案批准，等待规格复核
- 目标：用 Python + PyQt6 + PyQt6-Fluent-Widgets 复刻 PortHelper 1.8.8 的常用功能，交付 Windows 11 风格的单文件 exe
- 交付名：`PortHelper Fluent`，可执行文件 `PortHelperFluent.exe`
- 程序版本：`1.0.0`；功能参考版本：PortHelper `1.8.8`

## 1. 背景与目标

原程序 `PortHelper.exe` 是温子祺开发的「单片机多功能调试助手 V1.8.8」，PE32/MFC，包含串口、USB HID、网络客户端/服务端、蓝牙、51 代码向导、校验、编码转换、图片取模、点阵生成等 12 个标签页。

本项目不复用原程序代码、图标、截图、驱动或外部助手，只依据公开可见的交互与算法事实，独立实现一个更现代、更易用的替代品。目标是：

1. 覆盖日常嵌入式调试的常用链路：串口、TCP/UDP、TCP 服务端、USB HID。
2. 覆盖高频工具：校验、进制/编码转换、图片取模、点阵生成、C51 代码与 Keil 工程生成。
3. 界面达到 Windows 11 Fluent 水准：侧边导航、卡片布局、浅色/深色、清晰的信息层级、完整中文文案。
4. 单文件 exe 可直接双击运行，无 venv、无安装器、无需管理员权限。

## 2. 逆向证据与边界

已完成的证据：

- PE 头、导入表、资源表、版本信息。
- 26 个对话框模板、90 条 String Table、程序内中文提示与标签页名称。
- 内嵌 Keil 工程模板、校验算法源码资源、6 张 Keil 配色预览图、串口监视驱动与蓝牙助手载荷（仅识别，不复用）。
- 证据产物位于 `analysis/`，包括 `parsed/dialogs.txt`、`parsed/strings.txt`、`parsed/tabs_and_ui.txt`、`strings/key_hits.txt`、`extract_res.py`。

证据边界：

- 未运行原程序，避免其驱动安装、注册表写入、联网更新等副作用；因此没有运行时行为录像。
- 原生代码级行为（如串口线路控制细节、CRC 变体参数、51 计算边界）以资源、字符串和内嵌源码为证据；若 Ghidra 可用，再用 REA 的 `decompile` 做定点校验，否则在实现中采用标准算法并用独立测试向量验证。
- REA 的使用：先执行 `inspect-pe-resources` 固化资源证据；Ghidra 化程序分析为增强项，不阻塞交付。所有结论区分「观察」「推断」「未知」。

明确排除、不硬抄的部分：

1. 蓝牙调试：原程序调用独立蓝牙助手 exe，依赖外部驱动与配对流程。
2. 串口高级监视：依赖 32 位内核驱动，安装/卸载具有系统侵入性。
3. CH372：依赖厂商 DLL，无法在纯 Python 单文件中可靠复刻。
4. 在线自动更新：原下载地址与更新链路不属于本项目交付。
5. Keil 一键配色替换：会修改外部 Keil 配置，改为不做。

## 3. 用户界面

采用 `FluentWindow` + 左侧导航，分为三组：

- 通信：串口调试、网络调试、网络服务器、USB HID
- 工具：校验计算、编码转换、图片取模、点阵生成、C51 向导
- 其他：设置与关于

视觉与交互要求：

- 跟随系统浅色/深色；Mica 可用则启用，否则使用 Fluent 亚克力或纯色降级，不因 Mica 失败而阻塞启动。
- 卡片式参数区、分栏收发区、状态胶囊、信息条、空状态、复制按钮、文件拖放。
- 每个输入控件提供中文标签和工具提示；错误就近显示，不用技术性 traceback 打扰用户。
- 快捷键：`Ctrl+Enter` 发送，`Ctrl+K` 清空当前面板，`F5` 刷新设备/适配器，`Ctrl+S` 保存当前记录。
- 窗口尺寸、分栏比例、最近目录、每页参数自动记忆。
- 深色/浅色下收发区使用等宽字体，HEX 与文本颜色区分方向；日志可暂停、可继续、可导出。
- 界面字体使用 Microsoft YaHei UI，收发区使用 Cascadia Mono/Consolas；Qt6 高 DPI 缩放策略为 PassThrough，125%/150% 下不得出现文字截断。
- 关于页明确列出不支持项与原因，避免用户误以为功能缺失是 bug。
- 首次启动直接进入串口页，用空状态和工具提示引导，不弹强制教程。

## 4. 功能规格

### 4.1 串口调试

- 端口枚举：端口名、描述、VID/PID、序列号；刷新按钮；无设备时显示空状态。
- 参数：波特率（预设 + 可编辑）、数据位 5–8、停止位 1/1.5/2、校验 None/Odd/Even/Mark/Space、流控 None/RTS-CTS/XON-XOFF、字符编码 ANSI/GBK/UTF-8。
- 编码语义：`GBK` 固定为 cp936；`UTF-8` 为 utf-8；`ANSI` 使用系统当前代码页（本机 cp936，与 GBK 结果相同），并在工具提示中说明，避免用户误以为两者必然不同。
- 打开/关闭；DTR、RTS 开关；BREAK 脉冲；CTS/DSR/RING/RLSD 只读状态。
- 接收区与发送区可独立切换文本/HEX、时间戳、自动滚动、暂停、清空、另存为 TXT/CSV。
- 发送：多行文本、`Ctrl+Enter`、文本/HEX、追加 CR/LF/CRLF、连续发送间隔 10–60000 ms、发送文件（文本或二进制）、收发字节计数、重新计数；HEX 输入在发送前校验，非法字符与奇数长度就地标红，不发送半截数据。
- 多项发送：8 个槽位，每槽独立文本/HEX/追加换行/单次发送/循环发送；保存与载入 JSON 方案。
- 会话记录：按方向、时间、长度、HEX/文本查看完整收发记录，导出 CSV；明确标注这是「本程序会话记录」，不是系统级串口监视。
- 端口信息：描述、VID/PID、序列号、位置；错误时给出「检查设备连接/是否被占用」的可读提示。

### 4.2 网络调试

- 目标地址支持 IP 或域名；域名解析按钮；TCP 客户端与 UDP 两个模式。
- TCP：源/目的端口、连接/断开、本地端点、连接状态；UDP：绑定/解绑、源/目的端口。
- Ping：调用系统 `ping.exe`，显示原始输出与成功/失败结论；不做原始套接字 ICMP。
- 收发区：TCP 与 UDP 分栏，独立文本/HEX、时间戳、暂停、清空、保存。
- 发送：TCP 发送、UDP 发送、连续发送、文件发送、计数；文本编码 ANSI/GBK/UTF-8。
- 辅助：域名转 IP、本地网卡信息（地址、掩码、网关、MAC、状态）、会话记录导出 CSV。
- 错误：连接超时、连接被拒绝、端口占用、DNS 失败、网卡无连接均落到信息条与记录，不崩溃。

### 4.3 网络服务器

- 监听地址（全部网卡或指定地址）、端口、启动/停止、最大客户端数 1–64。
- 客户端列表：IP:端口、连接时间、接收/发送字节、当前选中状态；支持断开选中客户端。
- 接收区显示来源 `IP:端口` 前缀；发送支持「发给选中客户端」或「广播给全部客户端」。
- 文本/HEX、时间戳、编码、连续发送、文件发送、清空、保存 CSV、计数。
- 客户端上线/下线、超过上限、端口占用、发送失败均有明确提示。
- 纯 TCP 原始数据，不实现 HTTP/WebSocket。

### 4.4 USB HID

- 使用 hidapi 枚举设备：路径、VID、PID、产品名、厂商、序列号、Usage Page/Usage、接口号。
- 搜索框按 VID/PID/产品名过滤；刷新；无设备时正常显示空列表。
- 打开/关闭；读取线程；发送 Output Report；报告 ID 可选（无编号报告为 0），报告长度可自定义 1–1024 字节，默认 64 字节并按此填充/截断；带编号报告时首字节为报告 ID。
- 接收区显示 Input Report，支持文本/HEX、时间戳、暂停、清空、保存；发送支持文本/HEX、连续发送、文件、计数。
- 设备拔出或读取失败时自动关闭并提示，不遗留线程。
- 页面信息条明确：CH372 需要厂商 DLL，本程序只支持标准 HID；不伪装支持 EP1/EP2 厂商语义，界面使用「发送 Report / 接收 Report」表述。

### 4.5 校验计算

- 输入模式：文本（编码可选）、HEX、文件（流式读取，显示大小/进度/取消）。
- 算法：
  - 求和 8/16/32 位
  - XOR-8 / BCC
  - 奇校验、偶校验
  - Intel HEX 校验和
  - TCP/IP 校验和
  - CRC-8 预设：CRC-8/MAXIM、CRC-8/SAE-J1850、CRC-8/BLUETOOTH
  - CRC-16 预设：CRC-16/IBM(MODBUS)、CRC-16/CCITT-FALSE、CRC-16/XMODEM、CRC-16/KERMIT
  - CRC-32 预设：CRC-32/ISO-HDLC
  - 自定义 CRC：宽度 8/16/32、多项式、初值、结果异或、输入/输出反射
- 「计算后取反」开关；结果以 HEX/DEC/BIN 显示，16/32 位支持大小端展示；每项可复制。
- 源码预览：展示本程序对应算法的 Python 实现，供用户移植参考；不冒充原程序源码。
- 已知向量测试：CRC-32/ISO-HDLC("123456789")=0xCBF43926，CRC-16/MODBUS=0x4B37，CRC-16/CCITT-FALSE=0x29B1，CRC-8/MAXIM=0xA1。

### 4.6 编码转换

页面内用分段控件切换七个子工具：

1. 进制转换：输入 2–36 任意进制，输出二进制/八进制/十进制/十六进制；32/64 位；有符号补码视图；复制。
2. Bin/Hex/Text：Bin→Text 把二进制字节转为大写十六进制文本；Hex→Text 把十六进制文本解码为选定编码的文本文件；Hex→Bin 把十六进制文本转为原始字节文件。提供文件选择、编码选择、输出路径、进度、前 N 字节预览、错误提示。
3. 数码管：输入 0–9/A–F，显示 a–g/dp 段，输出共阴/共阳 HEX 与二进制；也可点击段反向生成编码。
4. 调色板：颜色选择器 + RGB/HEX 输入，输出 24 位 HEX、RGB565、RGB332、RGB888，显示色块并复制；说明其用于彩屏与二维码位图调色。
5. GIF→BMP：载入 GIF，逐帧预览、调速、输出宽高，批量导出 `名称_0001.bmp` 等；进度与失败文件列表。
6. 音频→C：载入 WAV/MP3，显示格式/采样率/声道/时长，播放/停止，生成 C 数组（采样率、长度、数组名可改），保存 `.c/.h`；MP3 优先用本机 ffmpeg 解码，缺失时明确提示只支持 WAV。
7. 二维码：文本输入、纠错等级 L/M/Q/H、尺寸、边框、前景/背景色，预览并保存 PNG/BMP；不做扫码识别。

### 4.7 图片取模

- 输入：单张图片或文件夹；支持 Pillow 可读的常见位图；拖放导入。
- 参数：输出类型（C 数组、BIN、LVGL 8、LVGL 9）、扫描方式（水平/垂直）、扫描方向（自左到右/自右到左/自上到下/自下到上）、颜色深度（1/8/16/24/32）、字节序（小端/大端）、输出宽高（可锁定比例）、背景色、透明色、反色阈值（1 位）。
- 预览：原图与输出图并排；显示尺寸与颜色深度；参数变化实时刷新。
- 导出：C 文件包含文件名、尺寸、格式、扫描方式注释，数组名由文件名清洗得到；BIN 为原始数据；批量转换显示总进度、成功/失败列表；同名冲突自动加序号。
- 16 位色彩使用 RGB565，8 位使用 RGB332；1 位按阈值二值化；透明像素使用指定背景色。
- 测试：小图验证数组长度、像素值、扫描方向、字节序、批量命名。

### 4.8 点阵生成

- 输入：文字或 BMP；文字使用系统字体（`QFontDatabase` 列表），字号 8–64，粗体/斜体，BMP 阈值与反色。
- 参数：扫描方式（水平/垂直）、取模走向（四种）、位序（MSB/LSB）、每页字符数、点颜色/背景色、网格显示、缩放。
- 预览：点阵网格分页显示；单击单元格可切换黑白，编辑结果参与导出；一键恢复为文字渲染结果。
- 导出：C 数组（含宽高、扫描方式、位序注释）、BIN、复制；长文本自动分页；BMP 文件夹批量转换，逐文件生成 C 文件。
- 测试：固定字符串在指定字体/字号下的点阵尺寸与位模式；四种扫描方向的转置关系；单元格编辑改变输出。

### 4.9 C51 向导

- 晶振频率 0.1–100 MHz（预设 11.0592/12/24），6T/12T 倍速。
- P0–P3 端口引脚复选，实时显示十六进制值，生成端口初始化代码。
- 中断：EA、EX0、ET0、EX1、ET1、ES、ET2；各中断高/低优先级；外部中断电平/下降沿触发。
- 定时器 0/1/2：模式、门控、运行、定时时间（µs）或重载值；自动计算 TH/TL，溢出与模式约束给出警告。
- 串口：方式 0–3、波特率、REN、SM2、TB8/RB8、SMOD、波特率发生器（T1/T2）；自动计算重载并检查冲突。
- 功耗：正常/空闲/掉电；软件延时 µs；警告面板汇总冲突与建议。
- 输出：C 代码预览（含寄存器设置注释、中断服务函数、main 框架）；导出 `Main.c`、`M51Project.Uv2`、`M51Project.Opt`、自写极简 `STARTUP.A51` 到用户选择目录；不复制 Keil 原始文件。
- 测试：12 MHz/11.0592 MHz 下定时器与波特率寄存器已知值；冲突警告；工程文件存在且可读。

### 4.10 设置与关于

- 主题（跟随系统/浅色/深色）、强调色、默认编码、日志字体大小、自动滚动、最大显示行数、退出确认、窗口几何记忆。
- 打开配置目录、打开日志目录、导出配置、重置配置。
- 关于：版本、独立复刻声明、原作者与功能参考说明、不支持项（蓝牙/内核监视/CH372/自动更新/Keil 配色替换）、依赖许可、REA 证据说明。
- 不提供自动更新与外部下载。

## 6. 并发、数据流与性能

- 串口与 HID 各用一个工作线程：读循环带 50 ms 超时，发送队列由互斥锁保护；关闭时置停止标志、join 线程、关闭句柄。UI 不直接调用阻塞式 read/write。
- 网络使用 `QTcpSocket` / `QTcpServer` / `QUdpSocket`，在 Qt 事件循环内运行；高频率 `readyRead` 先累积到缓冲，由 33 ms 定时器批量刷新界面。
- 所有接收数据先写入 `SessionLog`（记录方向、来源、时间、原始 bytes），界面按当前显示模式渲染；暂停只停止渲染，不停接收与计数。
- 显示区最多保留 20000 行/块；原始会话日志上限 8 MB，超出后丢弃最旧数据并在状态栏提示；收发字节计数不受丢弃影响。
- 记录导出：TXT 使用 UTF-8；CSV 使用带 BOM 的 UTF-8，便于 Excel 直接打开且中文不乱码。
- 批量图片、批量点阵、文件校验、音频解码放入 `QThreadPool` 任务，提供进度与取消；取消后 200 ms 内停止。
- 目标：1 MB/s 串口输入下界面不冻结；页面切换 < 100 ms；冷启动 < 4 s（含 onefile 解压）。

## 7. 配置与路径

- 默认配置：`%APPDATA%\PortHelperFluent\config.json`；日志：同目录 `logs/app.log`（1 MB × 3 轮转）；崩溃报告：`logs/crash-<时间>.txt`。
- 便携模式：exe 同目录存在 `portable.flag` 时，配置与日志写入 exe 同目录 `data/`；写入失败则回退 AppData 并提示。
- 不写注册表，不安装服务/驱动，不请求管理员权限。
- 配置使用版本号与默认值合并；损坏文件先备份为 `config.bad-<时间>.json` 再回退默认值。
- 导出文件默认使用原文件目录或用户上次选择的目录；批量导出前检查可写性。

## 8. 错误处理与日志

- 统一 `safe_slot` 装饰器包裹 Qt 槽函数：捕获异常、写日志、显示信息条，绝不把异常抛回 Qt 事件循环。
- 启动自检：断言 qfluentwidgets 的窗口控件实际继承自 PyQt6 的 QWidget；若安装被 PyQt5 版本覆盖，弹框说明原因并退出，避免白屏。窗口化 exe 的未捕获异常不会显示 traceback，因此自检必须自行捕获并写入日志。
- 全局 `sys.excepthook` 与 Qt 消息处理器：写崩溃报告、弹可读对话框、退出前刷新日志。
- 设备/网络/文件错误一律使用「发生了什么 + 可能原因 + 下一步」的中文提示；技术细节写入日志。
- 串口/HID 设备拔出、TCP 对端关闭、UDP 绑定失败、DNS 超时、文件占用、权限不足均有专门分支。
- 关闭窗口时停止所有线程、关闭句柄、保存配置；如仍有连续发送/服务端监听，先确认再退出。

## 9. 测试策略

1. 核心单元测试（pytest，不启动 GUI）：校验向量、编码往返、C51 寄存器、RGB565/RGB332、扫描方向、点阵位模式、配置迁移。
2. Qt 离屏测试：实例化每个页面、切换主题、模拟输入、断言状态文字与控件可用性；不把截图作为正确性证据。
3. 网络集成测试：本机 TCP 回环、TCP 服务端多客户端、UDP 回环、端口占用错误。
4. 串口测试：注入 FakeSerial，验证打开/关闭、文本/HEX、时间戳、连续发送、计数、异常提示；不依赖真实硬件。
5. HID 测试：枚举在无设备时返回空列表；无效路径打开失败不崩溃；有设备时的读写由用户手工验证。
6. 打包自检：`PortHelperFluent.exe --selftest --report <path>` 检查依赖、PyQt6 绑定、资源与版本并写 JSON；`--smoke-test` 启动主窗口 1.5 s 后退出。
7. 手工验收：真实串口设备、HID 设备、TCP/UDP 对端、Keil 打开生成工程、图片/字模导出结果。

验收门槛：

- 所有核心测试与 Qt 离屏测试通过。
- 单文件 exe 从独立临时目录启动，不依赖源码目录或系统 site-packages（`--selftest` 与 `--smoke-test` 均返回 0）。
- 十个页面均可切换，浅色/深色无不可读文字。
- 串口/网络/HID 的错误路径不崩溃。
- 导出文件可被目标软件（Keil、图片查看器）打开。

## 14. 风险与应对

- HID 无真机：完成枚举、空状态与错误路径测试，读写留手工验收项；不宣称已验证真实设备。
- 串口无真机：用 FakeSerial 覆盖逻辑，真实链路由用户验收。
- Mica 不可用：启动时探测并降级，属性断言替代截图判断。
- 单文件启动慢/杀软误报：提供 SHA-256、构建日志与 `--selftest`；不使用 UPX；不请求管理员权限。
- 高速数据卡顿：批量刷新、显示上限、原始日志上限与取消机制作为验收项。
- 51 计算边界：用公开公式与独立测试向量，警告覆盖溢出/冲突；不追求与原程序逐位一致的错误行为。
